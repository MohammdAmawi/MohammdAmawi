## Engineering profile

I'm **Mohammad Amawi**, a **third-year Software Engineering student** focused on **Full-Stack Web Development**, with a long-term direction toward **DevOps and Cloud**.

My strengths are in **Software Requirements Engineering, Software Modeling, System Design, and Database Design**. I enjoy understanding what a system needs to do, representing how it works, and organizing its components and data before moving into implementation.

I'm developing my practical web-development skills through learning and projects. My aim is to connect clear analysis and thoughtful design with software I can explain, improve, and eventually help deploy and maintain.

<br/>

| Step | What I focus on |
| :--- | :--- |
| **Understand** | The problem, user needs, requirements, and constraints. |
| **Model** | The system's structure, behavior, and relationships. |
| **Design** | Components, interactions, and the organization of data. |
| **Build & review** | Turn the design into practical work, check behavior, and improve through feedback. |
